# Vrinda Store Sales Analysis 📊

## Project Overview
This project analyzes Vrinda Store sales data using Microsoft Excel to understand sales performance, customer purchasing patterns, and business trends.

## Objectives
- Analyze overall sales performance.
- Understand customer demographics and purchasing behavior.
- Identify sales trends across different categories and channels.
- Present key insights through an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- Data Cleaning and Data Analysis
- Pivot Tables and Charts
- Interactive Dashboard and Slicers

## Project File
**Vrinda Store Analysis.xlsx** — Contains the Excel sales analysis project and dashboard.

## Key Learnings
- Organizing and analyzing sales data.
- Using Excel to summarize business information.
- Creating visualizations to communicate insights.
- Understanding how data supports business decisions.
